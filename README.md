# Bk Minimize On Close
Becky! Internet Mail Ver.2 の、メインウインドウの「閉じる」ボタンを最小化に変更するプラグイン。

## 機能
通常のクリックでは最小化。Alt + クリックでは Becky! Internet Mail を終了させることができる。  
メニューやタスクトレイ内から`終了`を選択した場合も同様に終了させることができる。  

### 使用方法
インストール方法
1. [Release](https://github.com/niyari/BkMinimizeOnClose/releases) からプラグイン DLL (以下、DLL) が含まれているアーカイブをダウンロード。  
2. ダウンロードしたファイルを展開し、他のプラグインと同様に PlugIns フォルダ内に DLL をコピーする。  
(通常は `C:\Program Files (x86)\RimArts\B2\PlugIns` に設置)  
3. Becky! Internet Mail を再起動することで、Bk Minimize On Close プラグインを読み込むための確認が行われる。読み込みを許可する事で動作する。  
4. プラグインの設定画面では、起動時からの最小化に貢献したクリック数を確認することができる (Becky! Internet Mail を終了した際にカウントはリセットされる)。  

透明性を担保するため、GitHub の機能を使用して DLL を直接ビルド (ソースコードから DLL ファイルを自動的に作成) を行っている。  
メーラーというソフトウェアの性質上、配布されているバイナリ (DLL) をそのまま使用する事が気になる場合はソースコードを取得し自身の環境でコードの精査とビルドを行うとよい。  

## リポジトリ内のファイルについて
ソリューション内に C++ 版、C# 版のプロジェクトが存在するが、C# 版のプロジェクトは浪漫枠である。  
ファイルサイズは C++版 15KB 程度、C# 版 2000KB 程度となる。ファイルサイズが小さくて済む C++ 版を利用するとよい。  
C# 版は Release のビルド済みバイナリには含まれないため、使用するにはソースコードからビルドする必要がある。

プラグイン作成にあたり、Becky! Plug-In SDK の一部がリポジトリに含まれている。

## ほか
`Alt + クリック`で終了する挙動は、**意思を以て閉じる操作** を行った判断として実装されている。  
Becky! Internet Mail の起動時にロードするプラグインの選択設定は、記載されている通り次回起動時に反映されるものである。設定変更後は再起動後に動作確認を行うこと。

プラグインに頼らず、標準でこの機能があれば良いですね。
